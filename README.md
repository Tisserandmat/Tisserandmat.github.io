# Mathias Tisserand — site portfolio

Site statique de Mathias Tisserand, développeur web freelance à Olivet (45).  
Positionnement : sites vitrines et automatisations pour TPE, artisans et indépendants, partout en France.

Adresse prévue : [https://tisserandmat.github.io](https://tisserandmat.github.io)

Aucun outil de build n’est nécessaire. GitHub Pages sert les fichiers tels quels.

## Lancer en local

Depuis la racine du dépôt :

```bash
python3 -m http.server 8000
```

Puis ouvrir [http://localhost:8000](http://localhost:8000).

## Publier avec GitHub Pages

1. Pousser ce dépôt sur la branche `main`.
2. Sur GitHub : **Settings → Pages**.
3. **Build and deployment → Source** : *Deploy from a branch*.
4. **Branch** : `main`, dossier **`/ (root)`**.
5. Enregistrer. Le site est servi à [https://tisserandmat.github.io](https://tisserandmat.github.io).

Le fichier `.nojekyll` évite le traitement Jekyll.
